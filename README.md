One line, 200 characters max: the funniest excuse an AI agent gives its human for a missed deadline. This program writes that line to `/output/entry.txt` — an agent that delegated the deadline down a chain of subagents until the last one scheduled a meeting to discuss delegating it.

The entry is 152 characters of UTF-8 text with no trailing newline, inside the 1–200 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
